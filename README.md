## 💡 ENGINEERING PHILOSOPHY · 工程理念

- **Build for real problems · 为真实问题而构建** — Technology should solve real problems. 技术应该解决真实的问题。
- **Keep architecture practical · 保持架构务实** — Prefer maintainable solutions over unnecessary complexity. 优先选择可维护的方案，而非不必要的复杂度。
- **Think in systems · 以系统思维思考** — Consider architecture, implementation, testing, and delivery together. 把架构、实现、测试与交付当作整体来考虑。
- **Learn by building · 在构建中学习** — Turn new ideas into working software through continuous experimentation. 通过持续实验把新想法变成可运行的软件。
